# MarketGo

MarketGo es una aplicacion web de comercio electronico desarrollada con Node.js, Express, PostgreSQL, Handlebars y Firebase Authentication.

El sistema permite gestionar productos, categorias, clientes, carritos de compra y pedidos.

## Tecnologias utilizadas

- Node.js
- Express.js
- PostgreSQL
- Handlebars
- Bootstrap
- JavaScript
- Firebase Authentication
- Express Session

## Requisitos

Antes de ejecutar el proyecto se necesita tener instalado:

- Node.js
- npm
- PostgreSQL
